# Abdul Basit Siddiqui — Engineering Portfolio

A modern, high-performance portfolio engineered with React, TypeScript, and Tailwind CSS. Featuring interactive canvas particles, a floating glass island dock with full Light & Dark mode support, and an integrated interactive shell terminal.

## 🌟 Highlights
- **Flagship Project — Wapsi (वापसी):** Recognized in the **Top 250 out of 13,000+ teams across India**. Multi-lingual conversational AI tax concierge ("Munshi ji") supporting 23 Indic languages with Form 16 intelligent parsing.
- **Projects Showcase:** RegDiff (Autonomous Statutory Intelligence), Aura-Attendance (Real-Time Tracker), and LeetCode Medium/Hard algorithmic mastery.
- **Floating Island Navbar:** Minimalist glass dock with theme switcher (Light / Dark mode), tactile sound effects, and resume download.
- **Interactive Command Terminal (`Ctrl + K`):** Built-in CLI shell supporting `help`, `wapsi`, `projects`, `skills`, `cat resume`, and `sudo hire basit`.
- **Tactile Audio FX:** Web Audio API sound synthesizer without external audio assets.

## 🛠️ Tech Stack
- **Frontend:** React 19, TypeScript, Tailwind CSS
- **Icons & Polish:** Lucide React, Canvas Confetti
- **Audio:** Web Audio API Synthesizer
- **Bundler:** Vite

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation
```bash
git clone https://github.com/Basit-94/Portfolio.git
cd Portfolio
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
